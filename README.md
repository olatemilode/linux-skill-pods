# linux-skill-pods

This repo holds my weekly documentation for the Linux Essentials course. Each week I reflect on the discussion sessions and my personal study time, then write it up here so I have a clear, permanent record of what I learned, how I learned it, and where I struggled.
Every entry follows the same structure:
	•	What I learned: the concepts
	•	How I learned it: sessions, study time and practice
	•	Challenges: what was hard and how I got through it
	•	Key takeaways: the main points to remember
